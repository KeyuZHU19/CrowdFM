# CrowdSI-FM: Amortized System Identification for Crowd Foundation Models

## One-sentence definition

CrowdSI-FM pretrains a permutation-equivariant model to infer the latent data-generating mechanism of an entire crowd dataset, then updates only that low-dimensional mechanism at deployment and enables the update only when task-disjoint held-out annotations provide sufficient predictive evidence.

## 1. Research problem

Let workers be indexed by `i in [M]`, tasks by `k in [N]`, and options by `a in [K]`. We observe a sparse annotation graph

```math
G=\{(i,k,A_{ik}):O_{ik}=1\},
```

where `O_ik` is the assignment/missingness indicator and `Y_k` is an unavailable task truth.

CrowdFM learns one fixed map

```math
G\mapsto q_\theta(Y_k\mid G)
```

across synthetic training worlds. The unresolved problem is that a new deployment dataset can be generated by a different worker population, task distribution, assignment policy, class-bias pattern, or dependence mechanism. A fixed zero-shot forward pass has no explicit object to update when this mechanism changes.

The CrowdSI research question is:

> Can a crowd foundation model amortize an initialization for the deployment crowd mechanism, identify that mechanism from unlabeled annotations at test time, and adapt aggregation only when independent predictive evidence shows that adaptation improves over the zero-shot mechanism?

This is not a claim that task-truth correctness can be certified without an anchor. It is a system-identification and safe-adaptation problem.

## 2. Separately exchangeable mechanism model

CrowdSI-FM follows the worker--task--edge factorization suggested by separately exchangeable arrays. A deployment dataset has a global mechanism latent

```math
Z_{\mathcal D},
```

worker and task representations `U_i,V_k`, latent truths `Y_k`, assignment indicators `O_ik`, and responses `A_ik`:

```math
Z_{\mathcal D}\sim p(Z),
```

```math
O_{ik}\sim p_\theta(O_{ik}\mid U_i,V_k,Z_{\mathcal D}),
```

```math
Y_k\sim p_\theta(Y_k\mid V_k,Z_{\mathcal D}),
```

```math
A_{ik}\mid O_{ik}=1,Y_k
\sim
p_\theta(A_{ik}\mid Y_k,U_i,V_k,Z_{\mathcal D}).
```

The model is permutation invariant to worker and task identifiers and equivariant in its worker/task outputs.

## 3. Amortized compositional mechanism posterior

The CrowdFM backbone first produces worker, task, and option embeddings. A set encoder pools:

- mean worker representation;
- mean task representation;
- mean option representation;
- mean encoded annotation-edge representation.

It returns a diagonal Gaussian posterior

```math
q_\phi(Z_{\mathcal D}\mid G)
=
\mathcal N(\mu_G,\operatorname{diag}(\sigma_G^2)).
```

A mechanism sample is routed over learned primitives `B_1,...,B_R`:

```math
\alpha(Z)=\operatorname{softmax}(WZ+b),
```

```math
C(Z)=\sum_{r=1}^R\alpha_r(Z)B_r.
```

The convex mechanism basis is intended to support unseen compositions of mechanisms rather than memorizing one categorical simulator family.

## 4. Mechanism-conditioned decoders

Conditioned on `C(Z)`, CrowdSI-FM predicts three coupled objects.

### 4.1 Adapted task truth

```math
q_\theta(Y_k=c\mid G,Z).
```

This is a mechanism-conditioned replacement for the fixed CrowdFM task head.

### 4.2 Edge-conditioned emission law

For a queried worker--task pair:

```math
P_{ik}^{Z}(a\mid c)
=
\Pr_\theta(A_{ik}=a\mid Y_k=c,G,i,k,Z).
```

The shared scorer evaluates every candidate truth option and reported option, preserving variable `K`.

### 4.3 Annotation assignment law

```math
\pi_{ik}^{Z}
=
\Pr_\theta(O_{ik}=1\mid G,i,k,Z).
```

This prevents the sparse observation mask from being treated as ignorable by construction. Training uses hidden positive edges and sampled non-edges.

## 5. Pretraining objective

For two independently masked views `G_C^(1),G_C^(2)` of the same synthetic world, train

```math
\mathcal L
=
\lambda_Y\mathcal L_Y
+
\lambda_A\mathcal L_A
+
\lambda_O\mathcal L_O
+
\lambda_{KL}\mathcal L_{KL}
+
\lambda_C\mathcal L_C.
```

### Truth aggregation

```math
\mathcal L_Y
=-\sum_k\log q_\theta(Y_k\mid G_C,Z).
```

### Masked response generation

When synthetic truth is known:

```math
\mathcal L_A
=-\sum_{(i,k)\in H}
\log P_{ik}^{Z}(A_{ik}\mid Y_k).
```

For real data without truth, use the task-joint latent-truth likelihood:

```math
\log p(A_{H_k}\mid G_C,Z)
=
\log\sum_c q_\theta(c\mid G_C,Z)
\prod_{i:(i,k)\in H_k}P_{ik}^{Z}(A_{ik}\mid c).
```

The product is inside a single truth summation per task. Multiplying edgewise marginal probabilities would incorrectly discard dependence induced by the shared unknown `Y_k`.

### Assignment generation

```math
\mathcal L_O
=-\sum_{i,k}
\big[O_{ik}\log\pi_{ik}^{Z}+(1-O_{ik})\log(1-\pi_{ik}^{Z})\big],
```

implemented with non-edge negative sampling.

### Mechanism regularization and view consistency

```math
\mathcal L_{KL}=D_{KL}(q_\phi(Z\mid G_C)\Vert\mathcal N(0,I)),
```

```math
\mathcal L_C
=
D_{SKL}
\big(q_\phi(Z\mid G_C^{(1)}),q_\phi(Z\mid G_C^{(2)})\big).
```

The consistency term forces the global latent to describe a dataset mechanism rather than one particular sampled subgraph.

## 6. Test-time Bayesian system identification

Given a context graph, the amortized encoder supplies

```math
q_0(Z)=\mathcal N(\mu_0,\operatorname{diag}(\sigma_0^2)).
```

Network weights are frozen. For an adaptation set `H_A`, optimize only a variational posterior

```math
q_A(Z)=\mathcal N(\mu_A,\operatorname{diag}(\sigma_A^2))
```

with generalized-Bayes objective

```math
\max_{q_A}
\frac{1}{\eta}
\mathbb E_{Z\sim q_A}
\big[\log p_\theta(A_{H_A}\mid G_C,Z)\big]
-
\beta D_{KL}(q_A\Vert q_0).
```

Thus deployment adaptation is low-dimensional system identification, not unconstrained neural-network fine-tuning.

## 7. Task-disjoint e-value gating

A context/audit split first hides responses from the model. Audit tasks—not individual edges—are then divided into folds `H_A,H_B`. Entire tasks remain in one fold so the two folds do not share a latent truth.

Adapt `q_A` on fold A and evaluate its mixture predictive likelihood on fold B:

```math
E_{A\to B}
=
\frac{\int p_\theta(A_{H_B}\mid G_C,Z)q_A(Z)dZ}
{p_\theta(A_{H_B}\mid G_C,Z=\mu_0)}.
```

Define `E_{B->A}` symmetrically and combine

```math
E=\frac12(E_{A\to B}+E_{B\to A}).
```

Under the fixed plug-in null `Z=mu_0`, conditional independence of disjoint tasks, and normalized numerator predictive distributions,

```math
\mathbb E_0[E]\le 1,
```

hence

```math
\Pr_0(E\ge1/\alpha)\le\alpha.
```

The implementation therefore uses adaptation only when `E >= 1/alpha`. If supported, it refits the mechanism posterior on all held-out audit tasks and performs final aggregation with the selected posterior mean.

The guarantee is deliberately narrow: it controls replacing the fixed plug-in mechanism under its own null. It does not make a misspecified learned model correct and does not certify task truths.

## 8. Why this is more than a predictive audit

The earlier `PredictiveCFM` supplied a fixed conditional emission law and tested whether deployment responses matched it. CrowdSI-FM instead:

1. represents the crowd mechanism as an explicit global latent;
2. learns compositional mechanism primitives across datasets;
3. models both annotation values and assignment/missingness;
4. performs unlabeled test-time mechanism inference;
5. uses task-disjoint predictive evidence to decide whether adaptation is warranted;
6. changes final aggregation when the evidence gate opens.

The residual audit remains useful as a diagnostic/localization ablation, but it no longer carries the main novelty.

## 9. Required empirical claims

A main-conference paper requires all of the following.

### In-prior performance

CrowdSI-FM must retain CrowdFM's zero-shot aggregation quality when the amortized mechanism is already adequate.

### Held-out mechanism families and compositions

Pretraining must omit entire families or combinations, including class bias, coalitions, assignment bias, and difficulty/noise interactions. Test whether adaptation recovers performance rather than merely recognizing simulator IDs.

### Safe adaptation

Report:

- false adaptation rate under the plug-in null;
- e-value growth under mechanism shift;
- base versus always-adapt versus evidence-gated accuracy;
- risk--coverage or gain--false-adaptation curves;
- performance versus adaptation annotation count.

### Mechanism identification

Use simulator metadata only for evaluation: family classification, continuous-parameter recovery, primitive-composition stability, and posterior contraction.

### Real datasets

Evaluate zero-shot and adapted aggregation across the CrowdFM benchmark suite. The method must not require gold labels for adaptation; truth is used only for retrospective accuracy measurement.

## 10. Limitations

- The e-value statement is conditional on the fixed plug-in null and task independence; richer global uncertainty requires a conditional null predictive denominator.
- Mechanism latents are identifiable only up to transformations unless simulator supervision or structural restrictions are added.
- Observationally equivalent truth/noise mechanisms cannot be separated without trusted labels, metadata, temporal structure, or interventions.
- Explicit assignment modeling needs careful negative sampling because absence can mean either non-assignment or missing data.
- A sufficiently flexible simulator remains a scientific bottleneck; performance on its own mechanism vocabulary is not evidence of real-world system identification.
